The embedded dmg_boot and cgb_boot binaries in open_boot_roms.h are the open
SameBoy bootstrap programs, not Nintendo BIOS images.
Source: ../SameBoy/BootROMs at SameBoy commit 26a56bd6a122a6318a456abd80558408742d5adf; Expat (MIT) license in ../SameBoy/LICENSE.
Copyright (c) 2015-2026 Lior Halphon.

Rebuild from the pinned sources:
 python coreGB/bridge/build_boot_roms.py coreGB/build/rgbds
The recipe uses official RGBDS v1.0.4 Windows x64 tools from
https://github.com/gbdev/rgbds/releases/download/v1.0.4/rgbds-win64.zip
SHA-256 bd1d7e386f290afd57f4ea9a7353bfcd4ae10884a94c5c1f2fc42a75db7f97e6
verified against the GitHub release asset's published digest before extraction.
The PB12 compressor is a direct Python translation of SameBoy BootROMs/pb12.c.
No proprietary ROM or BIOS data is included.
